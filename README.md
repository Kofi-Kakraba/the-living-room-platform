# The Living Room Platform

A custom apparel e-commerce and business management platform for The Living Room, Ghana.

## Planned Features

- Ready-made apparel e-commerce store
- Interactive customer apparel design studio
- Visual website page editor
- Customer and enquiry management
- Quotations and order management
- Payment tracking
- Production management
- Business reporting

## Technology Stack

- Next.js
- React
- TypeScript
- Tailwind CSS
- Supabase
- Puck
- Fabric.js
- Vercel

Project foundation not yet implemented.
