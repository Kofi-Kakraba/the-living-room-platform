# Garment master assets

This folder contains approved photographic garment masters used by the Design Studio.

Add the two transparent PNG files from the supplied asset pack here:

- `hoodie-white-back.png` — white pullover hoodie, rear view; used as the recolouring source.
- `hoodie-black-back.png` — black pullover hoodie, rear view; used for the exact black option.

Do not use these rear-view files for the front view. Add separate front masters when supplied.

The current renderer preserves the alpha channel and fabric luminance. Review every cutout edge before using the images for customer-facing production previews.
